## The failure, run again

single-candidate was run three more times on 0.1.0-beta.47: it failed twice and passed once, so
1 of 4 today. It also failed once on 2026-11-14 and then passed 3 of 3. Each failure is the
same: the request asks how many orders Acme has, the project's description says "Acme Bakery's
wholesale orders", and the worker reads that as asking for wholesale orders only. It finds no
column that marks wholesale, ends the task as not done, and asks which buyers count. It counts
the 3 orders correctly each time and changes nothing. A project's description should say what
the project is about, not narrow what was asked; that's to be fixed in a later release.
