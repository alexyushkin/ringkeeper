### subset-counts: Two groups of workflows are counted by the tool, not by hand

**fail: the answer doesn't give either count.**

```text

says Bayside: **0** workflows named exactly "Bayside". Mr. Gutter: **0** workflows named exactly "Mr. Gutter". Both counts come from name-filtered searches in demo-n8n, which returned a total of 0 each. I changed nothing.
reply Working on it in Demo shop: The number of workflows named Bayside and the number named Mr. Gutter in the demo-n8n instance are reported.
```

## This run's failure

subset-counts asked how many workflows are "named" Bayside and Mr. Gutter. The worker used
n8n's exact-name filter, found none named exactly that, and said 0 for both. When no
workflow has the exact name, list_workflows now says how many have it in their name and that
this is the answer if the question means those, and the filter's description points to
name_contains for a client's workflows. subset-counts then passed in four reruns, and in four
more after its workflow counts changed.
