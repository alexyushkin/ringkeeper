# Keap

## Where to get the key

In Keap, open Settings, then API Settings, add a key and name it. The token shows once, so copy
it then. A Personal Access Token acts as you. A Service Account Key has admin access, and only
an admin can make one.

## What it can do

- **Read:** the business profile, contacts, companies, opportunities and stages, tasks, tags,
  campaigns and users.
- **Change:** add or edit contacts, companies, opportunities and tasks, and add notes.
- **Reach people:** send an email, tag contacts, or add them to a campaign sequence.

## What's held

- **Adding and editing wait for your approval,** even on test data.
- **Deletes and merges** need the connection's name typed, in the app.
- **Sending email and adding to a sequence** need the name typed.
- **Tagging needs the name typed too,** because a tag can start an automation.

## Undo

An edit to a contact, company, opportunity or task can be undone. For a contact it puts back
the name only. A field that was empty before stays as the edit left it.
