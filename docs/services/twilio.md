# Twilio (texts and calls)

## Where to get the key

In the [Twilio console](https://console.twilio.com/): copy the **Account SID**
from the home page, then **Account › API keys & tokens › Create API key**
(Standard) and copy its SID and secret.

## What it can do

- **Read:** phone numbers, messages, calls.
- **Change:** send a text.

## What's held

**Every text waits for your approval** before it's sent.

## Undo

A text or a call can't be taken back.
